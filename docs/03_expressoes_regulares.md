# Expressões Regulares

Neste módulo vamos trabalhar com expressões regulares simples.

Operadores usados:

- `ab` para concatenação;
- `a|b` para alternância;
- `a*` para repetição zero ou mais vezes;
- `a+` para uma ou mais vezes;
- `a?` para opcional;
- parênteses para agrupar.

Exemplos:

```text
ab
a|b
a*
a(b|c)
```

O programa deve ler a expressão, montar uma árvore simples e informar a posição quando houver erro.
