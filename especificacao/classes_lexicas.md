# Classes Léxicas da DrawLang

**INICIO** — palavra reservada que indica o início de um programa DrawLang.

**FIM** — palavra reservada que indica o final de um programa ou de um bloco de repetição.

**MOVER** — palavra reservada que representa o comando de movimentação do cursor na direção atual.

**VIRAR** — palavra reservada que representa o comando de alteração da direção do cursor.

**CANETA** — palavra reservada utilizada para definir a cor da caneta.

**LEVANTAR** — palavra reservada utilizada para desativar temporariamente o desenho durante a movimentação do cursor.

**BAIXAR** — palavra reservada utilizada para ativar o desenho durante a movimentação do cursor.

**IR** — palavra reservada utilizada para mover o cursor diretamente para uma coordenada.

**QUADRADO** — palavra reservada utilizada para desenhar um quadrado.

**CIRCULO** — palavra reservada utilizada para desenhar um círculo.

**TRIANGULO** — palavra reservada utilizada para desenhar um triângulo equilátero.

**REPETIR** — palavra reservada utilizada para iniciar um bloco de comandos que será executado várias vezes.

**COR** — classe que representa as cores reconhecidas pela linguagem: `vermelho`, `azul`, `verde`, `amarelo`, `preto` e `branco`.

**NUMERO_INTEIRO** — sequência de dígitos, opcionalmente precedida por `+` ou `-`, que representa um número inteiro.

**NUMERO_DECIMAL** — sequência numérica contendo uma parte inteira e uma parte decimal separadas pelo caractere `.`.

**COMENTARIO** — sequência iniciada pelo caractere `#` e que se estende até o final da linha, sendo ignorada pelo interpretador.

**ESPACO_EM_BRANCO** — espaços e tabulações utilizados para separar elementos da linguagem e ignorados durante a análise léxica.

**QUEBRA_DE_LINHA** — caractere que indica o término de uma linha e separa os comandos da DrawLang.
